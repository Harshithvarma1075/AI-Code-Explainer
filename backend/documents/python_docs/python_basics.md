# Python Basics

## Introduction

Python is a high-level, interpreted, object-oriented, and general-purpose programming language developed by Guido van Rossum and first released in 1991. It is designed to be easy to read and write, making it one of the most popular programming languages for beginners and professionals.

Python is widely used in:

- Web Development
- Artificial Intelligence
- Machine Learning
- Data Science
- Automation
- Cybersecurity
- Cloud Computing
- Desktop Applications
- APIs

## Features of Python

- Simple and readable syntax
- Interpreted language
- Platform independent
- Dynamically typed
- Large standard library
- Open-source
- Supports multiple programming paradigms

## Python Syntax

Python uses indentation instead of curly braces.

```python
if True:
    print("Hello World")
```

Incorrect:

```python
if True:
print("Hello")
```

This produces an IndentationError.

## Common Beginner Mistakes

- Wrong indentation
- Missing colon after if, for, while, def
- Using reserved keywords as variable names
- Mixing tabs and spaces

---

## Best Practices

- Follow PEP-8
- Use meaningful variable names
- Keep functions small
- Avoid unnecessary global variables
